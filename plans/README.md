## Findings considered and rejected

- A direct browser/web migration was rejected: Gamma Manager requires local
  `user32`, `gdi32`, `dxva2`, WMI, registry, tray, and AppData access.
- Replacing the Windows display backend with an unverified Native SDK service
  was rejected: the SDK's TypeScript service tier supports ordinary static-tier
  TypeScript and subprocesses, but does not document direct Win32/WMI FFI.
